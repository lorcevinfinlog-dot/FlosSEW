# FloxZert

**Браузерная студия для рисования и покадровой анимации.** Рисуйте, собирайте сцену из объектов и работайте с кадрами прямо в браузере — без установки приложения и собственного сервера.

[Открыть редактор](./index.html)

> Веб-версия предназначена для статического хостинга, включая GitHub Pages. Проекты сохраняются в браузере на этом устройстве.

## Возможности

- **Рисование:** кисть, карандаш, ластик, заливка, линия, прямоугольники, эллипсы, треугольники, многоугольники, звёзды и текст.
- **Выделение и редактирование:** перемещение, изменение размера и поворот объектов; рамочное и свободное лассо; множественное выделение с `Ctrl` или `Cmd`; группировка и разгруппировка.
- **Внешний вид:** заливка и обводка, цвета, градиенты, прозрачность, скруглённые углы, тени и размытие.
- **Слои и библиотека:** порядок и прозрачность слоёв, группы объектов и библиотека сохранённых деталей.
- **Анимация:** покадровый таймлайн, копирование кадров, ключевые кадры, motion tween, кривые easing, onion skin и предпросмотр.
- **Рабочая область:** масштабирование, сетка, привязка объектов и штрихов к сетке; дополнительный режим показывает диагонали `\` и `/` в каждой клетке и привязывает точки рисования к ним.
- **Экспорт:** PNG-изображение текущей сцены. Можно выбрать масштаб экспорта от 1× до 4×.
- **Сглаживание Flox:** локальное распознавание простых форм и линий без загрузки модели и без обращения к API.
- **Друзья и совместная работа:** запросы в друзья, общие проекты с ролями редактора/зрителя и общий тулбокс деталей. Изменения общего проекта появляются у участников при синхронизации.

## Быстрый старт

1. Откройте опубликованную страницу GitHub Pages или файл `index.html`.
2. Выберите инструмент на панели слева и рисуйте на холсте.
3. Используйте панель и таймлайн для настройки объектов, слоёв и анимации.
4. Нажмите **Экспорт**, чтобы скачать текущую сцену в PNG.

### Полезные клавиши

| Клавиша | Действие |
| --- | --- |
| `V` | Выделение и перемещение |
| `B` | Кисть |
| `N` | Карандаш |
| `E` | Ластик |
| `G` | Заливка |
| `R` | Прямоугольник |
| `O` | Эллипс |
| `L` | Линия |
| `T` | Текст |
| `Shift` при рисовании | Ровные стороны фигуры или фиксированный угол линии |
| `Ctrl` / `Cmd` + клик | Добавить объект к выделению или убрать его |
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` или `Ctrl+Y` | Повторить |
| `Ctrl+K` | Командная палитра |

Горячие клавиши можно посмотреть и переназначить в **Настройки → Горячие клавиши**.

## Публикация на GitHub Pages

Эта папка подготовлена как содержимое корня отдельного GitHub-репозитория.

1. Загрузите **содержимое** `WEBS` в корень репозитория — не помещайте саму папку `WEBS` вложенным каталогом.
2. Включите отображение скрытых файлов и также загрузите `.nojekyll` и `.github/workflows/pages.yml`.
3. Отправьте изменения в ветку `main`.
4. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.
5. Дождитесь завершения workflow **Deploy FloxZert web app** во вкладке **Actions**.

Workflow собирает сайт из файлов корня и публикует его через GitHub Pages. Если основная ветка репозитория называется не `main`, измените имя ветки в `.github/workflows/pages.yml`.

## Вход через Google, GitHub и Apple

Кнопки в **Настройки → Аккаунт и облако** активны, когда в `cloud-config.js` указан `apiBase`; отключить их можно параметром `oauth: false`. Реализованные OAuth-маршруты находятся в серверных пакетах `SERVER` и `HOST`. Ключи, private key Apple и секрет Turnstile хранятся только в переменных окружения API — не добавляйте их в `WEBS`, Git или frontend-конфигурацию.

| Адрес | Что делает |
| --- | --- |
| `GET /api/auth/providers` | Возвращает, какие OAuth-провайдеры настроены |
| `GET /api/auth/oauth/{provider}/start?return_to=…&state=…` | Проверяет origin возврата по `FLOXZERT_WEB_ORIGINS`, создаёт state/PKCE и перенаправляет к провайдеру |
| `GET /api/auth/oauth/google/callback` и `/github/callback` | Сервер обменивает код и проверяет профиль. Apple отправляет `POST /api/auth/oauth/apple/callback` в режиме `form_post`; подпись и claims ID token проверяются сервером. |
| `POST /api/auth/oauth/exchange` | Одноразовый короткоживущий код обменивается на FloxZert bearer-сессию; provider-токены не попадают в URL |

Перед включением OAuth настройте API:

1. `FLOXZERT_WEB_ORIGINS` — точный origin опубликованного сайта, например `https://my-editor.github.io`.
2. `FLOXZERT_PUBLIC_BASE_URL` — публичный HTTPS-origin API, например `https://floxzert-api.example.com`.
3. Переменные конкретного провайдера: `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET`, `GITHUB_CLIENT_ID`/`GITHUB_CLIENT_SECRET` или `APPLE_CLIENT_ID`/`APPLE_TEAM_ID`/`APPLE_KEY_ID`/`APPLE_PRIVATE_KEY`.
4. В консоли каждого OAuth-провайдера зарегистрируйте callback `https://<адрес API>/api/auth/oauth/<provider>/callback`. Адрес должен совпадать посимвольно, включая путь.
5. В `cloud-config.js` укажите только публичные `apiBase` и Turnstile Site Key. `TURNSTILE_SECRET_KEY` задаётся отдельно на backend.

Apple требует Apple Developer Program, Services ID, домен/Return URL и ключ `.p8`. Для `APPLE_PRIVATE_KEY` можно задать PEM в несколько строк или с `\n`. Успешный вход требует верного Apple Team ID, Key ID и Services ID.

Для запроса друзей и совместного доступа пользователь должен войти в аккаунт. Проекты можно открыть только принятому другу: владелец управляет доступом, редактор может сохранять, зритель — только читать. Синхронизация холста работает через версии проекта и периодическую проверку изменений; одновременные конфликтующие сохранения не объединяются автоматически.

## Хранение данных и ограничения веб-версии

- Автосохранение работает локально в хранилище браузера. Данные привязаны к браузеру и адресу сайта; они не синхронизируются между устройствами.
- Очистка данных сайта в браузере может удалить сохранённый проект. Не очищайте их, если хотите сохранить работу.
- Облачные проекты, аккаунты и история версий требуют отдельно размещённого API и не включаются одной только публикацией на GitHub Pages.
- Друзья, общий тулбокс и совместные проекты также требуют запущенного API, включённых OAuth/аккаунтов и постоянного хранилища сервера.
- Генеративный ИИ-чат в статической сборке не подключён. Сглаживание Flox — встроенный геометрический алгоритм, а не нейросеть.
- Экспорт сцены из веб-редактора доступен в PNG. Сохранение проекта в `.flosk` предусмотрено в desktop-приложении; веб-версия умеет импортировать проектные файлы.
- Каталог **Дополнительные функции** также содержит идеи и незавершённые модули. Включение пункта каталога само по себе не добавляет отсутствующую функцию.

Не добавляйте секретные ключи и пароли в файлы этого репозитория. Содержимое `cloud-config.js` предназначено для публичной конфигурации сайта; секреты, если для API они нужны, хранятся на сервере.
